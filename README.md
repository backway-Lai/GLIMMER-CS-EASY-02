# Step 1.指针与结构体

## 什么是指针
- 一般来说，在c语言中我们使用类型加`*p`的方式定义指针，其中类型可以有int整型或char字符型，而`*p`代表指针。
- 在同一个程序中，指针的大小一般是固定的（即地址），可以被改变的是指针指向的变量的大小。
- 指针占据几个字节一般只和操作系统架构有关：对于32位系统而言，地址是32bit时指针大小即是4字节；对于64位系统而言，地址是64bit时指针大小即是8字节。

### 野指针
野指针即指针变量中存储了一个无效地址，例如指针未初始化、数组越界、free内存后未将指针置于null中。而类似数组中的写越界，向野指针指向地址写入数据时会导致程序崩溃。与产生原因相对的，我们可以通过初始化指针地址、手动将不用的指针置于Null、避免数组越界等。

## 什么是结构体
- 结构体可以帮助我们在一个变量中赋予多种变量类型，并且使用typrdef为结构体取别名可以在使用时更加简便，以下是我的结构体定义：
![1](https://github.com/backway-Lai/GLIMMER-CS-EASY-02/raw/main/images/screen-shot2.png)
- 结构体指针可以理解为存放结构体变量地址的指针，作用是可以让函数修改结构体变量，这与前面普通指针用法类似。比方说，当我们希望可以在函数中修改结构体中某个变量的值时，可以定义一个结构体指针`*p`，并且通过`(*p).成员`或`p->成员`的形式完成，而这可以在函数中直接定位到变量的地址。
- **内存对齐**：即不同变量类型有不同的对齐要求，即起始内存地址应满足一定关系。比方说char的大小占用是1字节，对齐地址要求是1的倍数；而int的大小占用是4字节，对齐地址要求是4的倍数，以此类推。因此当前面的变量占用完内存后下一个可用的内存不一定符合下一个变量的存储需要，因此计算机会自动插入padding（一种空内存）来占用内存，直到内存地址符合下一个变量需求。
根据这种规则计算，不难看出我们刚刚定义的结构体占用字节如下：

>char[10]：0-9 占据10字节
>char: 10 占据1字节
>int: 12-15 占据4字节（11因为不是4的倍数，填充了padding作为空内存）
>double: 16-23 占据8字节
>综上，结构体字节占用为0-23，占据4字节

# Step 2.链操作

## 什么是链表？

- **数组与链表的区别**：
1. 首先，数组在内存中的储存方式一般是连续存储，也即是各变量在内存中地址紧挨着；而链表的变量可以不连续，而它们之间以指针相连接。
2. 其次，由于存储方式的不同，数组与链表各有优劣：数组因为数据连续，因此往往系统可以通过首变量地址与地址个数一次性定位到数组中的某一特定变量，因此读取速度较快，但也正因如此如果想要增删数组中变量就需要对后面所有变量做更改，较为麻烦；而链表与之相对的容易增删，只需要修改其中一两个指针关系即可，但同时如果需要读取链表中某一变量，则需要从头开始一个一个往后延伸。

- 单向链表：
1. 单向链表中的每个节点包含数据域与指针域，且指针指向是单向的，即不会指回之前的节点，而最后一个指针往往是Null，表示链表的结束。

### 添加元素
- **创建节点函数**：首先利用molloc动态申请内存。其次为数据域与指针域赋值（其中指针域默认Null，因此后续函数中要手动注明指针指向）。最后返回一个节点类型的返回值。

- **尾插函数**：引入一个移动指针p，通过p定位到尾节点，再将创建的新节点插入到尾节点与NUll中。
